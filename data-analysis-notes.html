1基期与现期 —— 一切计算的根基

资料分析的材料通常是统计数据（比如GDP、人口、产量），这些数据都带着时间。理解基期和现期，就是搞清楚"跟谁比"的问题。

一句话理解

现期 = 你正在研究的那个时间点的数据；基期 = 拿来作比较基准的那个时间点的数据。

简单说：现期是"现在"，基期是"过去"。现期是结果，基期是起点。

怎么判断谁是基期谁是现期？

看题目里的时间词。资料分析常见的表述：

题目表述 谁是现期 谁是基期 说明
"2024年比2023年增长了……" 2024年 2023年 后面的年份是现期，前面的年份是基期
"2024年同比增长8%" 2024年 2023年 "同比"就是跟去年同期比
"2024年上半年环比增长3%" 2024年上半年 2023年下半年 "环比"是跟紧挨着的上一期比
"2024年达到500亿元" 2024年 — 只给了一个时间点，没有基期
判断口诀

"比"字后面是基期，"比"字前面是现期。

"A比B增长" → A是现期，B是基期。就这么简单。

同比 vs 环比 —— 别搞混

高频考点

同比：跟去年同一时期比。比如2024年3月同比，就是跟2023年3月比。

环比：跟紧挨着的上一期比。比如2024年3月环比，就是跟2024年2月比。

当前时期 同比基期 环比基期
2024年Q22023年Q22024年Q1
2024年6月2023年6月2024年5月
2024年上半年2023年上半年2023年下半年
2024年2023年（通常不考环比）

2增长量与增长率 —— 变化的两种表达

知道了基期和现期，接下来要衡量"变化了多少"。变化可以用两种方式表达：绝对的量和相对的比例。

核心区分

增长量 = 变化了多少 绝对值（带单位，比如"亿元""万人"）

增长率 = 变化了多少 百分比（不带单位，用%表示）

举例理解

生活例子：工资涨了

小明2023年月薪5000元，2024年月薪6000元。

  • 增长量 = 6000 - 5000 = 1000元（涨了多少钱）
  • 增长率 = 1000 ÷ 5000 = 20%（涨了百分之几）

增长量说的是"涨了1000块"，增长率说的是"涨了20%"。同一个变化，两种说法。

易错提醒

题目问"增长了"还是"增长到"？

  • "增长了1000元" = 增长量，是增量
  • "增长到6000元" = 现期量，是总量
  • 一个字之差，答案完全不同！

增长率的其他叫法

资料分析里，"增长率"有很多"马甲"，看到这些都指增长率：

说法 含义 常见场景
增长率 / 增速最标准叫法通用
增幅 / 增幅增长幅度通用
同比增长跟去年同期比的增长率月度/季度数据
环比增长跟上一期比的增长率月度/季度数据
降低了 / 下降了负增长（增长率为负）数据减少时
特别注意

"降幅"和"降幅扩大"是两码事：

  • "下降了5%" → 增长率 = -5%
  • "降幅扩大了2个百分点" → 原来降3%，现在降5%（降幅从3%变5%）
  • 百分点是两个百分数相减的单位，不是百分数本身！

3四大核心公式体系

资料分析的公式说到底就是4个量之间的关系：基期量、现期量、增长量、增长率。记住这几个公式，90%的题都能列式。

公式一：增长率

增长率 = 增长量 ÷ 基期量 × 100%
增长率 = (现期量 - 基期量) ÷ 基期量

用工资例子验证：增长率 = (6000-5000) ÷ 5000 = 20% ✓

公式二：增长量

增长量 = 现期量 - 基期量
增长量 = 现期量 - 基期量

如果已知增长率，也可以反推：

已知增长率时的增长量
增长量 = 基期量 × 增长率

公式三：已知基期和增长率，求现期

现期量公式
现期量 = 基期量 × (1 + 增长率)

验证：5000 × (1 + 20%) = 5000 × 1.2 = 6000 ✓

公式四：已知现期和增长率，求基期

基期量公式（最常用！）
基期量 = 现期量 ÷ (1 + 增长率)

验证：6000 ÷ (1 + 20%) = 6000 ÷ 1.2 = 5000 ✓

公式关系图

四个量的关系可以用一个"十字公式"概括：

  • 已知基期 + 增长率 → 现期 = 基期 × (1+r)
  • 已知现期 + 增长率 → 基期 = 现期 ÷ (1+r)
  • 已知基期 + 现期 → 增长率 = (现期-基期) ÷ 基期
  • 已知基期 + 增长率 → 增长量 = 基期 × 增长率

核心思路：先判断题目给了哪两个量，求哪个量，再套对应公式。

5真题初体验

例题1：求基期量（最基础考法）

2024年某市GDP为4800亿元，同比增长20%。求2023年该市GDP。

解题思路

第一步：判断给了什么 → 现期量(4800) + 增长率(20%)

第二步：求什么 → 基期量

第三步：套公式 → 基期量 = 现期量 ÷ (1 + 增长率)

计算：4800 ÷ 1.2 = 4000亿元

例题2：求增长量

2023年某省粮食产量为500万吨，2024年同比增长10%。求2024年比2023年增长了多少万吨？

解题思路

第一步：判断给了什么 → 基期量(500) + 增长率(10%)

第二步：求什么 → 增长量

第三步：套公式 → 增长量 = 基期量 × 增长率

计算：500 × 10% = 50万吨

例题3：求增长率

2024年某企业利润为880万元，2023年为800万元。求同比增长率。

解题思路

第一步：判断给了什么 → 现期量(880) + 基期量(800)

第二步：求什么 → 增长率

第三步：套公式 → 增长率 = (现期 - 基期) ÷ 基期

计算：(880-800) ÷ 800 = 80 ÷ 800 = 10%

6易错点提醒

易错1：基期和现期搞反

"A比B增长"——B是基期（分母），A是现期（分子）。

做反了增长率就变成倒数。比如增长20%的题，做反了变成 ÷1.2 变成 ×1.2，答案直接错。

易错2："增长"与"增长到"混淆

"增长了1000" → 增长量 = 1000

"增长到1000" → 现期量 = 1000

差一个"到"字，意义完全不同。审题务必看清楚。

易错3：百分数与百分点混淆

"增长率提高了2个百分点" vs "增长率提高了2%"——

  • 百分点是做减法：原来10%，提高了2个百分点 → 现在12%
  • 百分数做乘法：原来10%，提高了2% → 10% × (1+2%) = 10.2%
  • 资料分析里几乎都用"百分点"来描述变化！
易错4：降幅与下降

"下降了5%" → 增长率 = -5%，现期比基期少

"降幅为5%" → 同上，增长率 = -5%

"降幅收窄2个百分点" → 原来降5%，现在降3%（降幅变小了）

"降幅扩大2个百分点" → 原来降5%，现在降7%（降幅变大了）

7年均增长率与年均增长量

前面学的增长率、增长量都是两个年份之间的变化。但资料分析经常考"一段时间内平均每年"的变化——这就是年均增长率和年均增长量。

一句话理解

年均增长率 = 跨多年的平均每年增长率（几何平均，不是简单算术平均！）

年均增长量 = 跨多年的平均每年增长量（算术平均，简单除法）

年均增长量 —— 简单除法

年均增长量的逻辑很直白：总共涨了多少，分摊到每年。

年均增长量
年均增长量 = (现期量 - 基期量) ÷ 年数

举例：年均增长量

某市2019年GDP为2000亿元，2024年GDP为3000亿元。求年均增长量。

解题思路

第一步：确定基期(2019, 2000)和现期(2024, 3000)

第二步：算年数 → 2024 - 2019 = 5年

第三步：套公式 → 年均增长量 = (3000-2000) ÷ 5 = 200亿元/年

年数怎么数？

2019到2024，年数 = 2024 - 2019 = 5（不是6！）。

口诀：直接相减。2024-2019=5年。从2019年底到2024年底，中间跨了5个年度。

注意区分：如果题目说"2019-2024年共6年的数据"，那是把首尾都算进去了（6个数据点），但增长只发生了5次。年均增长量用的是间隔年数=5。

年均增长率 —— 几何平均（开方！）

年均增长率就不能简单相除了，因为每年的增长率是复利效应——前一年的增长会叠加到后一年。所以要用开方来算。

年均增长率（核心公式）
现期量 = 基期量 × (1 + 年均增长率)n

反过来求年均增长率：

已知基期和现期，求年均增长率
年均增长率 = n√(现期量 ÷ 基期量) - 1

其中 n = 间隔年数（同上，直接相减）。

举例：年均增长率

某市2019年GDP为2000亿元，2024年GDP为3000亿元。求年均增长率。

解题思路

第一步：确定基期(2000)、现期(3000)、年数n=5

第二步：先算 比值 = 3000 ÷ 2000 = 1.5

第三步：开5次方 → 5√1.5 ≈ 1.0845

第四步：减1 → 年均增长率 ≈ 8.45%

验证：2000 × 1.08455 ≈ 2000 × 1.5 = 3000 ✓

最容易犯的错！

年均增长率 ≠ 总增长率 ÷ 年数

上题总增长率 = (3000-2000)/2000 = 50%，50% ÷ 5 = 10% —— 这是错的！

因为复利效应，实际年均增长率只有8.45%，不是10%。简单除法会高估年均增长率。

正确做法是开n次方，不是直接除。

年均增长率 vs 年均增长量 对比

对比项 年均增长量 年均增长率
本质 算术平均 几何平均（复利）
公式 (现期-基期) ÷ n n√(现期÷基期) - 1
计算难度 简单除法 需要开方（较难）
单位 带单位（亿元、万人等） 百分比%
考点频率 中等 高频！几乎必考

年均增长率的估算技巧

考场上开n次方不可能精确算，需要估算。常用方法：

估算法一：居中代入法

比如已知比值=1.5，n=5，试代入几个值：

  • 如果年均增长率=8%：1.085 ≈ 1.47 → 偏小
  • 如果年均增长率=9%：1.095 ≈ 1.54 → 偏大
  • 所以年均增长率在8%-9%之间，更接近8.5%

选项如果给的是8%、9%、10%、11%，选8.5%或9%（看选项哪个更接近）。

估算法二：选项代入验证

直接拿选项的数值算 (1+r)n，看哪个最接近"现期÷基期"的比值。

这是考场上最实用的方法——不需要会开方，只需要会算(1+r)的n次方。

"年均"相关的其他叫法

说法 含义
年均增长率 / 年均增速同义词，都是几何平均
年均增长量 / 年均增量同义词，都是算术平均
年均增长 / 平均每年增长看题目问"率"还是"量"来判断
复合增长率 / CAGR就是年均增长率（几何平均）
"n年间的年均增长率"n=间隔年数（首尾相减）

8经济术语专题

资料分析的材料大量来自统计公报、经济年鉴，里面会出现一批固定的经济术语。这些词本身不难，但如果不知道含义，题目就无从下手。下面按类型整理。

一、顺差与逆差 —— 进出口贸易

一句话理解

顺差（贸易盈余）= 出口 > 进口，赚外汇，钱往里流

逆差（贸易赤字）= 进口 > 出口，花外汇，钱往外流

贸易差额公式
贸易差额 = 出口额 - 进口额
情况 计算结果 叫法 通俗理解
出口 > 进口 差额为正 顺差 卖出去的多，赚了
出口 < 进口 差额为负 逆差 买进来的多，花了
出口 = 进口 差额为0 贸易平衡 收支平衡
记忆技巧

"顺"= 顺心，赚钱 = 出口多

"逆"= 逆心，花钱 = 进口多

再记一个：顺差 = 出口 - 进口（正数），把"出"放前面就对了。

例题：贸易差额计算

2024年某国出口总额8000亿美元，进口总额6500亿美元。求贸易差额并判断类型。

解题思路

差额 = 8000 - 6500 = 1500亿美元

结果为正 → 出口大于进口 → 顺差1500亿美元

常见考法陷阱

陷阱1：题目问"顺差增长了多少"，要先算出两年各自的顺差，再相减。不能直接用进出口额的增长率。

陷阱2："逆差扩大"vs"逆差缩小"——逆差本身是负数，扩大是绝对值变大（更亏），缩小是绝对值变小（好转）。

陷阱3："由逆差转为顺差"——说明从进口多变成出口多，是质变，不是量变。

二、基尼系数 —— 收入分配公平度

一句话理解

基尼系数 = 衡量一个国家/地区收入分配是否公平的指标，取值0到1之间。

数值越大 = 越不平等（差距越大）；数值越小 = 越平等。

基尼系数区间 含义 说明
0绝对平均理论极值，所有人收入完全一样
0 - 0.2高度平均差距极小
0.2 - 0.3比较平均较为理想的状态
0.3 - 0.4相对合理国际公认的合理区间
0.4 - 0.5差距较大0.4是国际警戒线！
0.5以上差距悬殊收入分配严重不均
1绝对不平均理论极值，财富集中在一人手上
必记数字：0.4警戒线

基尼系数0.4是国际公认的收入分配警戒线。超过0.4说明收入差距偏大，需要引起重视。这个数字是常识判断和资料分析的高频考点。

记忆技巧

基尼系数越"基"（低），越公平——数值小说明大家收入接近。

反过来：基尼系数升高 = 贫富差距扩大；基尼系数下降 = 分配更公平。

三、恩格尔系数 —— 生活富裕程度

一句话理解

恩格尔系数 = 食品支出占总消费支出的比重。

数值越大 = 越贫困（吃饭花掉大部分钱）；数值越小 = 越富裕。

恩格尔系数公式
恩格尔系数 = 食品支出总额 ÷ 消费支出总额 × 100%
恩格尔系数 生活水平 通俗理解
59%以上贫困大部分钱都花在吃饭上
50% - 59%温饱刚够吃饱，其他消费少
40% - 50%小康吃饱之后还有余钱
30% - 40%相对富裕吃饭占比明显下降
20% - 30%富足吃饭只是小部分开支
20%以下极其富裕吃饭花费占比很低
记忆技巧

越有钱，吃饭占比越小——这是核心逻辑。因为收入增加后，吃饭的钱不会成倍增加，但会多花在教育、旅游、娱乐上。

所以：恩格尔系数下降 = 生活水平提高（好消息）。

例题：恩格尔系数计算

某家庭年消费支出10万元，其中食品支出3.5万元。求恩格尔系数并判断生活水平。

解题思路

恩格尔系数 = 3.5 ÷ 10 = 35%

35%落在30%-40%区间 → 相对富裕

基尼系数 vs 恩格尔系数 对比

对比项 基尼系数 恩格尔系数
衡量什么 收入分配公平度 生活富裕程度
取值范围 0 - 1（也写成0-100%） 0% - 100%
数值越大说明 差距越大（越不公平） 越贫困
数值越小说明 越公平 越富裕
关键数字 0.4 = 警戒线 59%以上贫困，20%以下极富
共同点 都是数值越小越好的指标
统一记忆

基尼系数和恩格尔系数，都是"越小越好"。

基尼小 → 分配公平；恩格尔小 → 生活富裕。两个都降低，说明社会发展得好。

贸易差额 = 出口 - 进口（相减）

一个加一个减，题目问"总额"还是"差额"要看清楚！

9速算技巧：截位直除

资料分析的公式都不难，真正卡人的是计算速度。一篇材料5道题限时5-6分钟，硬算除法必死。截位直除的核心思想是：分子一个字都不动，只把分母截成好算的数。

核心口诀（刘文超讲法）

分子不用算，只估分母即可。

分母保留三位有效数字，误差不超过 0.5%。

这两句话就是截位直除的全部。记住这个，比记一堆规则有用。

一、为什么只截分母

很多人一上手就想"分子分母都截短一点，算起来更快"。这是个误区。

同时截分子分母的两个问题

问题1 · 误差方向不可控：分子截一次产生误差，分母截一次又产生误差，两个误差可能叠加，也可能抵消，最后你根本不知道结果偏大还是偏小。

问题2 · 白省了力气：除法的计算量主要由分母决定。分母变成好算的数之后，分子留几位几乎不影响速度——反正都是一次除法。

只截分母的三个好处

好处1 · 误差只有一个来源：分子是精确值，误差全部来自分母，方向和大小都能算清楚。

好处2 · 误差有明确上限：保留三位有效数字时，误差一定在0.5%以内（后面会证明）。

好处3 · 判断方向极简单：分母截大了结果偏小，分母截小了结果偏大。只需要看一次。

误差方向（只截分母时）
分母变大 → 结果偏小 ↓
分母变小 → 结果偏大 ↑
一句话记住

分母反着来。分母往上截，答案往下走；分母往下截，答案往上走。

二、0.5% 误差上限是怎么来的

这个0.5%不是经验数字，是可以推导出来的。理解它之后你就敢放心大胆地截。

推导过程

保留三位有效数字，意味着从第四位开始四舍五入。第四位最多让第三位变动 0.5 个单位。

把分母的前三位记作 D（范围是 100 到 999）。那么：

相对误差 ≈ 0.5 ÷ D

D 最小是 100（分母首位是1的情况），此时误差最大：0.5 ÷ 100 = 0.5%

D 最大是 999，此时误差最小：0.5 ÷ 999 ≈ 0.05%

分母前三位 最大相对误差 说明
100 ~ 1990.50%首位是1，误差最大（最坏情况）
200 ~ 2990.25%
300 ~ 3990.17%
500 ~ 5990.10%
900 ~ 9990.06%首位是9，误差最小
重要推论

0.5% 是最坏情况（分母首位为1时）。实际做题中，分母首位越大，误差越小。

所以看到分母是 8xxx、9xxx 这种，保留三位的误差只有0.05%左右，几乎等于精确值。

对照：保留两位为什么不够用

同样的推导，保留两位时分母前两位 D 的范围是 10~99：

D=10 时误差 = 0.5 ÷ 10 = 5%（太大了！）

D=99 时误差 = 0.5 ÷ 99 ≈ 0.5%

也就是说保留两位的误差可能高达5%，是三位的10倍。这就是为什么标准做法是保留三位，而不是两位。

分母首位是1时，三位有效数字的误差接近0.5%的上限。如果选项间距小于1%，这时候就要考虑多留一位。

解题过程

四、保留几位：由选项间距决定

规则只有一条：保留位数带来的误差，必须小于选项间距的一半。每多留一位有效数字，误差缩小到十分之一，于是形成一把三档的尺子。

保留位数 误差上限 适用的选项间距 首位快捷判据
两位 5% 间距 > 10% 选项首位均不同
三位 0.5% 间距 1% ~ 10%（默认档） 选项首位有相同
四位 0.05% 间距 0.1% ~ 1% 首位、次位都挨着
两种问法，同一把尺子

课上常听到两种说法，其实是这张表的上下两半：

说法一（看首位）：首位均不同 → 保两位；首位有相同 → 保三位。

说法二（看间距）：间距 10% 以上 → 保两位；10% 以内 → 保三位；1% 以内 → 保四位。

中间的"三位"是两种说法共用的默认档，所以拼起来才是完整规则，不是互相矛盾。

两个判据打架时听谁的

首位判据是间距判据的快捷方式，但偏保守。例：选项 5.2 / 5.8 / 6.3 / 6.9，首位 5、5、6、6 有重复，按首位判据要保三位；可实际间距 (5.8−5.2)÷5.2 ≈ 11.5%，已过 10%，保两位也够。

听间距的更准，听首位的更安全。考场上时间紧，先扫首位；首位判不准或算完发现选项挨得近，再回头看间距。

计算 8934 ÷ 27651，选项：A. 32.1%   B. 32.3%   C. 32.5%   D. 32.8%

先看选项间距

选项间距只有 0.2%，而三位有效数字的误差上限是0.5%——误差比间距还大，可能算错选项。

解题过程

① 分子照抄：8934

② 分母留四位：27651 → 第五位是1，舍 → 27650

③ 直除：8934 ÷ 27650 ≈ 32.31%

④ 对选项：B. 32.3% ✓

误差仅 0.004%。（如果只留三位：8934÷27700 = 32.25%，误差0.18%，虽然也能选出B，但没有安全余量。）

实战判断法（动手前 3 秒）

扫一眼选项首位，立刻定位数：

首位互不相同（如 1.3 / 2.4 / 3.5 / 4.7）→ 保两位，除出首位即停

首位有重复（如 5.8 / 6.2 / 6.6 / 7.1）→ 保三位，这是默认档

首位、次位都挨着（如 32.1 / 32.3 / 32.5）→ 保四位

拿不准就按间距核一下：间距 >10% 两位、1%~10% 三位、<1% 四位。吃不准时往多留一位靠，宁可慢 5 秒也别算错。

五、截位规则细节

四舍五入，看第四位

保留三位有效数字，就看第四位：≥5 进1，<5 舍去。

⚠ 关键前提：必须四舍五入，不能"直接砍掉"

"截位"这个名字有误导性。0.5% 的误差保证，只在四舍五入时成立；如果按字面理解直接把后面的位砍掉，上界会翻倍到 1%。

原理：四舍五入时分母偏差 ≤ 半个单位 → 相对误差 ≤ 0.5÷D；直接截去时偏差可达一整个单位 → 相对误差 ≤ 1.0÷D。

反例：5000÷10999，真值 45.459%。

· 直接砍成 10900 → 5000÷10900 = 45.872%，误差 0.908%，破了 0.5% ✗

· 四舍五入成 11000 → 5000÷11000 = 45.455%，误差仅 0.009% ✓

50万组随机验证：直接截去时有 2.80% 的题会超出 0.5%——不是罕见情况，必须四舍五入。

🔥 高危场景：基期量公式的分母首位恒为 1

基期量 = 现期 ÷ (1+r)，分母 1+r 通常在 1.0~1.3 之间，前三位永远是 100~130，也就是永远踩在误差最差的那一档（≈0.5%）。

结论：基期类题目对保留位数最敏感。1+r=7.3% 时三位取 1.07，误差 0.280%；选项一挨近就要果断升到四位。

六、易错点汇总

五个常见错误

错误1 · 顺手把分子也截了——分子一动，误差就有了两个来源，方向不再可控，0.5% 的上界保证失效。注意：单看某一道题，"分子分母都截三位"有时反而更准（4587÷12683 就是这样：都截误差 0.069%，只截分母 0.134%）；只截分母胜在最坏情况可控——50万组实测，只截分母最大误差 0.4948%，都截 0.8319%。考场要的是"保证不出界"，不是"平均值好看"。分子照抄。

错误2 · 为了好算截成两位——这才是真正的致命伤。把1987当2000、把5237当5200，误差从0.15%涨到0.65%；两位的理论上界是 5%，是三位的 10倍。省下的那点口算时间不值得。

错误3 · 不看选项间距——选项挨得很近（间距小于1%）时还用三位，误差可能超过选项间距，选错。

错误4 · 忘记判断方向——算出的近似值刚好在两个选项中间时，靠"分母变大结果偏小"这一句就能定答案，不用重算。

错误5 · 把"截位"理解成直接砍掉——必须四舍五入，直接砍误差上界翻倍到 1%（见上文反例 5000÷10999）。

练习建议

截位直除的瓶颈不在"怎么截"，而在截完之后的那次除法。

建议：每天练20组三位数除法（如 4587÷127、3862÷105），练熟"任意数字÷三位数"取前两三位的速度。这才是提速的关键。

10速算技巧：多步连除

截位直除解决的是一次除法，但资料分析里还有更吓人的东西——除法套除法。最典型的就是"增长量之比"：两个增长量相除，而每个增长量本身就带一层 ÷(1+r)。四层运算叠在一起，硬算必死。多步连除的核心思想是：先把结构相似的量配对重组，把大分式拆成几个小分数，再截位约分。

典型题型：增长量之比
[ 123 ÷ (1+7.6%) × 7.6% ] ÷ [ 234 ÷ (1+32%) × 32% ]

一、三步走

多步连除 · 三步走
先重组再算
① 同位配对
分子、分母中结构相似的量放一块
现期量对现期量，增长率对增长率
② 重组变形
大分式拆成三个小分数相乘
(1+增长率) 交叉互换位置
③ 截位约分
各项分别截位（分母留三位）
约分化简后再相乘

二、配对规则：谁跟谁一组

把上面那个吓人的式子拆开看，分子分母里各有三样东西：现期量、增长率、(1+增长率)。配对规则就一句话：

配对口诀

现期量、增长率 → 平行配对：分子对分子、分母对分母，即 123/234、7.6%/32%。

(1+增长率) → 交叉配对：分母里的 (1+32%) 跑到分子，分子里的 (1+7.6%) 落到分母，即 (1+32%)/(1+7.6%)。

重组变形结果
123/234 × 7.6%/32% × (1+32%)/(1+7.6%)
为什么 (1+r) 是交叉的

因为它们在原式里是除数：分子里的 (1+7.6%) 待在分母位置，除过去就落到下面；分母里的 (1+32%) 反过来跑到上面。除数过河，位置互换——这是分数除法的本性，不是新规则。

三、例题演示

例题：增长量之比完整计算

计算 [ 123 ÷ (1+7.6%) × 7.6% ] ÷ [ 234 ÷ (1+32%) × 32% ]

解题过程

① 重组：拆成 123/234 × 7.6%/32% × (1+32%)/(1+7.6%)

② 截位：123/234 ≈ 0.53；7.6%/32% = 0.2375；1.32/1.076，分母留三位 → 1.32/1.08 ≈ 1.22

③ 相乘：0.53 × 0.2375 ≈ 0.126；0.126 × 1.22 ≈ 0.153

④ 方向检验：第三项 1.32/1.076 > 1，会放大结果；真实值 0.1532，方向一致 ✓

硬算验证：123÷1.076×0.076 ≈ 8.69；234÷1.32×0.32 ≈ 56.73；8.69 ÷ 56.73 ≈ 0.153——重组法一步到位，还顺便锁定了误差方向。

最大陷阱

(1+增长率) 配平了就全错。很多人顺手把 (1+7.6%)/(1+32%) 也写成"平行配对"，方向直接反掉。记住：只有 (1+r) 是交叉的，现期量和增长率都是平行的。

动笔前先估一眼第三项的方向（本例 1.32 ÷ 1.076 > 1，结果放大），算完对一下，配对错了马上能发现。

四、常用乘除速算（补充技巧）

多步连除拆完之后，拼的就是这些基础乘除的秒杀速度。五个必背套路：

技巧 公式 示例
一个数 × 1.5A×1.5 = A + A×0.5（加半）124×1.5 = 124 + 62 = 186
一个数 × 1.1A×1.1 = A + A×0.1（错位相加）124×1.1 = 124 + 12.4 = 136.4
一个数 ÷ 5A÷5 = A×2，小数点前移1位24÷5 = 48÷10 = 4.8
一个数 ÷ 25A÷25 = A×4，小数点前移2位24÷25 = 96÷100 = 0.96
一个数 ÷ 125A÷125 = A×8，小数点前移3位24÷125 = 192÷1000 = 0.192
口诀

×1.5 加半，×1.1 错位加；÷5、÷25、÷125，就是 ×2、×4、×8，再移小数点。

除以 5ⁿ 就是乘 2ⁿ 再把小数点前移 n 位——除数是5的幂，翻倍凑整就完事。

11判大小：分式 vs 1 —— 只比 a 和 b

资料分析里有一大类题只需要判断"上升还是下降"，不用算出具体值：比重比上年上升还是下降？人均收入提高了还是降低了？这类题的算式长相都一样 —— 一个分式 (1+a) ÷ (1+b)。而它跟 1 谁大，只取决于 a 和 b 谁大。

一句话总纲

先把分母统一写成 (1+b)，然后只比较 a 和 b —— 分子分母的"1"永远对消。

精确展开式（判升降 + 算数值 都靠它）
(1+a) ÷ (1+b) = 1 + (a − b) ÷ (1 + b)

这一个式子能同时读出两件事：

  • 方向（升降）：只看 a − b 的正负，也就是比 a 与 b 谁大 —— 不用动笔
  • 数值（变化率）：是 (a−b) ÷ (1+b)，不是 a − b
a 与 b 的关系 分式结果 实际含义 速记
a > b > 1 变大 / 上升 分子涨得更猛
a = b = 1 不变 同步涨跌，抵消
a < b < 1 变小 / 下降 分母涨得更猛
符号陷阱（最高频失分点）

题目写 ÷(1 − 1.5%) 时，b 是 −1.5%，不是 +1.5%。减号是 b 的一部分，必须带着负号一起比。

误把 1.5% 当正数和 39% 比，这道题结论碰巧相同；但换成 ÷(1+50%) 就会判反。

判大小 · 三步走
分式 vs 1
第一步：统一形式
  • 1 − x% 改写成 1 + (−x%)
  • 负号是 b 的一部分，不能丢
第二步：只比 a 与 b
  • a > b → 结果 > 1
  • a < b → 结果 < 1
  • 与 A、B 的具体数值完全无关
第三步：要数值再套公式
  • 定性：比 a、b 秒判升降
  • 定量：(a − b) ÷ (1 + b)
  • 两件事分家，别混用

落到三大高频题型

题型 表达式 判方向 计算式
平均数增长率 (1+a) ÷ (1+b) 比 a 与 b (a−b) ÷ (1+b)
（a=总量增速，b=份数增速）
比重变化 现期比重 × (a−b)/(1+a) 比 a 与 b 现期比重 × (a−b) ÷ (1+a)
（a=部分增速，b=整体增速）
倍数 / 比值变化 (1+a) ÷ (1+b) 比 a 与 b 同平均数增长率
隔年增长率 (1+a) × (1+b) 无需判方向 a + b + a·b
（这是乘法，规则不同）
隔年增长率是唯一例外

上面三类分子分母都是相除结构，才适用"比 a 与 b"。隔年增长率是相乘，规则完全不同：直接套 a + b + a·b，不存在"与 1 比大小"的判定。

结果 ≠ 1 + (a − b)

直觉上"分子涨 a、分母涨 b，净涨 a−b"，于是写成 1+(a−b)。这是错的，正确是 1 + (a−b)÷(1+b)。
多出来的"÷(1+b)"意味着：分母小于 1 时会把涨幅再放大一圈。b 越小，丢掉它越无所谓；b 越大（尤其为负且绝对值大），错得越离谱。

例题：(1+39%) ÷ (1−1.5%) 比 1 大还是小？

总收入涨 39%，人数降 1.5%，问人均收入是升是降、变化多少。

  • 统一形式：a = 39%，b = −1.5%（注意负号）
  • 定性判断：39% > −1.5% → 结果 > 1，人均上升
  • 定量计算：(39% + 1.5%) ÷ (1 − 1.5%) = 40.5% ÷ 0.985 ≈ 41.1%
  • 即 1.39 ÷ 0.985 ≈ 1.411

一句话核心

资料分析里的百分数，很多都约等于一个简单分数。把 12.5% 换成 1/8，除法就变成了乘法，心算难度断崖式下降。

一、为什么要背这张表

分数的两大优势

① 除法变乘法：算 4587×12.5% 要列竖式，算 4587÷8 心算就出来了。

当真实 r 偏离 1/n 在 ±4% 以内时：基期最大误差 0.800%，增长量最大误差 3.968%——放大了整整 5 倍。

原因：基期系数 1/(1+r) 接近 0.9，分子分母都是大数，r 的扰动被稀释；增长量系数 r/(1+r) 接近 0.1，r 本身就在分子上，扰动被完整保留还被小基数放大。

✅ 实操规则

算基期：r 与 1/n 相差在 0.3 个百分点内，可以放心用分数法。

算增长量：必须 r 恰好等于特殊分数（如题目明写 12.5%、25%、20%）才能用；只要是"约等于"，老老实实用截位直除。

一句话：基期敢近似，增长量要精确。

六、反向用法：把复杂除法凑成特殊分数

看到分母接近这些数就警觉

算 A÷B 时，如果 B 接近 A 的某个简单倍数，直接读出分数。

例：3856 ÷ 7712 → 一眼看出 7712 ≈ 3856×2 → 结果 ≈ 50%

例：2451 ÷ 9834 → 9834 ≈ 2451×4 → 结果 ≈ 25%

例：1287 ÷ 10250 → 10250 ≈ 1287×8 → 结果 ≈ 12.5%

配合选项使用

比重类题目选项常给 25%、33%、50% 这种整值。先扫一眼选项，如果全是特殊分数附近的值，就用倍数关系直接锁定，根本不用算。

七、易错点汇总

四个坑

坑 1 · 增长量用错分母——r=1/8 时增长量是现期的 1/9，不是 1/8。分母要加一。

坑 2 · 近似值算增长量——见上文第五节，误差放大 5 倍，这是最隐蔽的失分点。

坑 3 · 把 1/6 记成 16.6%——是 16.667%，考场写 16.7%。同理 1/12 是 8.333% 不是 8.3% 整。

坑 4 · 只背 1/n 不背 m/n——37.5%、62.5%、87.5% 出现频率很高，光背 1/8 不够用。

13分数比较 —— 除首位 + 看增速

比重、平均数、倍数类的比较题，本质都是几个分数比大小：四个选项四个分数，找最大或最小。两板斧按顺序用：先"除首位"，分不出胜负再"看增长速度"。

一句话总纲

先除首位定大半，首位相同看增速 —— 分子跑得快，分数就变大。

方法一：除首位（直除法）

每个分数只除出第一位，首位大的分数就大；首位相同再除第二位。分母保留几位，按第 9 节的规则定：选项首位互不相同保两位，首位有重复保三位。

分数 除首位 第二位 结论
456 ÷ 78 5（78×6=468 超了） — 先淘汰
512 ÷ 82 6（82×6=492） ≈ 6.24 最大
489 ÷ 81 6（81×6=486） ≈ 6.04 其次

方法二：看增长速度（增速比较法）

两个分数挨得近、除首位分不出胜负时，比分子增速和分母增速：

  • 分子增速 > 分母增速 → 后一个分数大
  • 分子增速 < 分母增速 → 前一个分数大

例：比较 233/456 与 256/487 —— 分子 233→256 涨 23，23÷233 ≈ 10%；分母 456→487 涨 31，31÷456 ≈ 7%。分子涨得快 → 256/487 更大（验证：0.511 < 0.526 ✓）。

为什么成立

256/487 = (233/456) × (1+10%) ÷ (1+7%) —— 就是第 11 节的"分式 vs 1"：分子增速 a > 分母增速 b，乘出来的因子大于 1，分数自然变大。

增速陷阱（最高频错法）

增速是涨量 ÷ 各自的基数，不是拿涨的绝对量直接比！上面 23 < 31，但 10% > 7% —— 不看基数比涨量，结论就反了。

方法切换信号：首位相同、数值挨得近 → 立刻换增速法，别死磕第二位、第三位。
